# ExoCore

A modular open-source framework for building a post-collapse exosuit system aligned with the Fractal Sovereignty protocol.

## Features
- Modular hardware interfacing for strength amplification, flight-assist, and environmental shielding
- Brain-Computer Interface (BCI) input support (e.g. OpenBCI, Neurable SDK)
- Power management integration for hybrid battery/capacitor systems
- ROS2-compatible real-time motion control and neural synchronization
- Secure override API for abandoned legacy infrastructure using symbolic glyph-key input
