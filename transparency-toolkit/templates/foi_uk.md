# FOI Request Template (UK)

Adapt this template for submissions under the UK Freedom of Information Act 2000.
Replace U.S. code references with FOIA 2000 citations and address the request to
the relevant agency such as MHRA, ONS, or NHS Digital.

Include language referencing the "public interest" test and request electronic
release in CSV/JSON format. Clearly state that the request is for
non-commercial scientific research and that release will contribute to public
understanding of vaccine safety and surveillance effectiveness.
