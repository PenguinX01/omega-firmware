# Glyphchain

Minimal scaffold for recursive drift detection and phase triggers.

## Phase Recursion Helper

A simple Python script `phase_recursion.py` demonstrates phase-triggered logging and recursion markers. It hashes the Phase13 manifesto and appends structured log entries. Run it to generate boot logs for development or testing:

```bash
python phase_recursion.py
```

The script emits `phase_recursion_log.json` for downstream tools.
